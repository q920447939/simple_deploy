# Simple Deploy 产品全景梳理

> 面向独立开发者/小团队的轻量化发布流水线工具

## 1. 产品形态（What it is）
- **定位**：将“本地脚本 + 远程 Ansible 分发”的部署流程产品化，降低每次手工操作成本。
- **形态**：单机桌面应用，配置本地存储，无多租户与复杂权限体系。
- **核心价值**：
  - **可复用**：步骤模板与参数可复用
  - **可追溯**：运行记录与日志可回溯
  - **可控**：执行前统一检查与参数验证

---

## 2. 产品内容（What it contains）

### 2.1 核心对象与边界
- **脚本**：本地执行步骤资产（如打包、生成文件）
- **Playbook**：控制端执行的远程部署资产
- **步骤模板**：脚本或 Playbook 的可复用封装，包含参数定义
- **批次**：由多个步骤组合而成的流水线模板
- **步骤**：批次中的执行单元（引用步骤模板并绑定参数）
- **运行记录**：批次的一次实际执行，包含状态、日志、结果

### 2.2 信息架构建议
- 概览
- 服务器（控制端 / 被控端）
- Playbook
- 步骤模板（脚本/Playbook 模板统一入口）
- 批次（流水线）
- 运行记录
- 设置

---

## 3. 交互形式（How it works）

### 3.1 概览页
**目的**：快速了解当前状态并下钻。
- 显示摘要卡片：状态 / 控制端 / 被控端数量 / 步骤数 / 最近运行 / 最近结果
- **交互细化**：
  - 点击“被控端 N 台” → 打开被控端清单（只读）
  - 点击“最近运行” → 跳转到运行记录详情（可选）

### 3.2 服务器页
**目的**：统一管理控制端与被控端。
- 控制端：连接信息、依赖检查
- 被控端：列表只读、批量可编辑（可选）

### 3.3 Playbook 页
**目的**：管理 Playbook 内容。
- 左侧列表，右侧详情/编辑
- **交互细化**：
  - 点击列表项立即刷新右侧详情
  - 未保存修改时切换需确认

### 3.4 步骤模板页
**目的**：创建/维护可复用步骤。
- 支持两类模板：
  - 脚本步骤（本地执行）
  - Playbook 步骤（控制端执行）
- 模板内容：基础信息 + 参数定义 + 文件槽位（Playbook） + 产物（脚本）
- **交互细化**：
  - 新增/编辑模板时支持参数别名与描述
  - 模板列表点击后右侧显示完整定义

### 3.5 批次页（核心工作区）
**目的**：组装与执行流水线。
- 顶部：批次状态、运行按钮、编辑批次
- 概览区：
  - 步骤列表（展开查看参数/文件槽位/当前输入值）
  - 参数快照入口
  - 统一编辑参数入口
- 运行记录区：
  - 左侧历史运行列表
  - 右侧日志/步骤进度
  - 支持“查看批次配置”回到概览

**交互细化**：
- 批次运行时自动切换到运行记录
- 运行记录查看时，顶部提示当前运行序号
- 参数编辑：支持全局批次参数编辑与单步编辑

### 3.6 参数管理
- 参数必须与步骤绑定展示
- 支持别名/描述（避免英文变量直露）
- 批次可设置统一 Ansible 参数

### 3.7 运行记录
- 列表展示执行结果与时间
- 点击可查看日志与步骤进度
- 支持参数快照复用

---

## 4. 生命周期（Lifecycle）

### 4.1 初始化阶段
1. 创建项目
2. 配置控制端/被控端
3. 创建步骤模板

### 4.2 编排阶段
1. 新建批次
2. 绑定步骤模板
3. 配置步骤参数
4. 配置 Ansible 默认参数

### 4.3 执行阶段
- 运行批次
- 记录日志/状态

### 4.4 复盘阶段
- 查看运行记录
- 使用参数快照
- 调整模板与批次

---

## 5. 用户体验原则
- **低心智负担**：用户只需理解“批次=流水线，步骤=节点”
- **避免割裂**：参数必须跟步骤一起展示
- **可见性优先**：关键信息一键下钻
- **复用优先**：常用步骤模板沉淀
